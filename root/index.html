🚀 Smart Export & Deployment

        
      

      

        
1
Smart URL (No Hosting Required)
The entire layout is encoded directly into a secure Data URI link. It works instantly inside an iframe or browser without a server.

        
2
Iframe Embed Block
Creates a responsive <iframe> tag wrapped around your Smart URL. Paste this directly into Notion, Webflow, or Canva's Embed block.

        
3
Download HTML (GitHub Pages)
If you prefer traditional hosting, download the standalone index.html file and push it to GitHub Pages.
